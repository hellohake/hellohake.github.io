# Free Image Hosting

This blog uses the public GitHub repository `hellohake/MyPicGoPicBed` as a free image bed.

## Recommended URL Format

Use raw GitHub URLs for stable free hosting:

```md
![alt](https://raw.githubusercontent.com/hellohake/MyPicGoPicBed/main/path/to/image.png)
```

Optional CDN URL when jsDelivr is available:

```md
![alt](https://cdn.jsdelivr.net/gh/hellohake/MyPicGoPicBed@main/path/to/image.png)
```

## Suggested Folder Layout

```text
blog/2026/post-name/image-name.png
```

Keep image names ASCII and URL-safe. Avoid spaces in filenames.
